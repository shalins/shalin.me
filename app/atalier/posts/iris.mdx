Iris was designed to be a comprehensive digital assistant for college students, helping them navigate their daily campus lives more efficiently.

## The Problem

College students often struggle with:
- Finding their way around large campuses
- Keeping track of assignments and deadlines
- Managing their class schedules
- Finding study spaces and resources
- Staying connected with campus events

## The Solution

We built Iris as an AI-powered assistant that could:
- Provide real-time navigation across campus
- Track and remind students of upcoming deadlines
- Suggest available study spaces based on current occupancy
- Notify students about relevant campus events
- Help with course selection and academic planning

## Technical Implementation

The project was built using:
- React Native for cross-platform mobile development
- Python backend with Flask
- MongoDB for data storage
- Machine Learning for personalized recommendations
- Integration with university APIs for real-time data

## Impact

While the project is no longer active, it served as a valuable learning experience in:
- Building mobile applications
- Working with AI/ML
- Understanding user needs
- Project management
- Team collaboration
